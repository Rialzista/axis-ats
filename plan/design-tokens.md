# Design Tokens — из Axis HRM

Снято с макета на Behance (скриншоты дашборда, карточек, style-секции). Значения точные там, где были подписаны
в макете (секция "Style"), остальное — подобрано по скриншотам.

## Цвета

| Токен | Hex | Назначение |
|---|---|---|
| `--color-bg-elevation-1` | `#141414` | базовый фон страницы |
| `--color-bg-elevation-2` | `#1F1F1F` | фон карточек/панелей (Dashboard widgets, Sidebar) |
| `--color-bg-black` | `#0D0D0D` | самый тёмный слой, если нужен (модалки поверх контента) |
| `--color-text-primary` | `#F2F2F2` | основной текст на тёмном фоне (в макете подписан как "White") |
| `--color-text-secondary` | `rgba(242,242,242,0.6)` | вторичный текст, подписи под цифрами (лейблы типа "vs last year") |
| `--color-accent` | `#25479D` | акцент: активные пункты меню, primary-кнопки, выделения в графиках |
| `--color-accent-hover` | `#2F58BE` | подобрать чуть светлее акцента для hover (нет в макете — рассчитать сами) |
| `--color-success` | `#4CAF50`-подобный зелёный | положительная динамика (+6.4% vs last year) |
| `--color-danger` | `#E5484D`-подобный красный | отрицательная динамика (-4.8% vs last year) |
| `--color-border` | `rgba(242,242,242,0.08)` | тонкие разделители в таблицах/карточках |

> Точный accent-hover и success/danger не подписаны в макете — сверьте по скриншоту глазами (zoom) и
> подберите ближайший HEX, это нормальная часть работы, а не блокер.

## Типографика

- Шрифт в макете: **Ingram Mono** (моноширинный). Он не бесплатный/не на Google Fonts — для проекта
  используйте свободный аналог с тем же характером: **JetBrains Mono** или **Space Mono** (оба на Google Fonts,
  оба моноширинные с похожим "техническим" настроением).
- Для длинных текстовых блоков (описания вакансий, заметки) моноширинный шрифт неудобен для чтения —
  добавьте второй шрифт для body-текста, например **Inter** или **IBM Plex Sans**, а моно оставьте для
  чисел/лейблов/заголовков разделов (как в макете: заголовки типа "AXIS", "HIRE", "STYLE" — моно).

| Токен | Значение |
|---|---|
| `--font-mono` | `'JetBrains Mono', monospace` |
| `--font-sans` | `'Inter', sans-serif` |
| `--font-size-display` | 48px (крупные цифры типа "556 employees") |
| `--font-size-h1` | 24px |
| `--font-size-h2` | 18px |
| `--font-size-body` | 14px |
| `--font-size-caption` | 12px |

## Форма и отступы

- Радиус скругления карточек/контейнеров: крупный, ~20–24px на внешнем контейнере дашборда, ~12px на
  внутренних виджетах.
- Внутренние отступы виджетов: ~20–24px.
- Grid gap между виджетами дашборда: ~16–20px.
- Sidebar: фиксированная ширина ~220px, иконки + текст, активный пункт подсвечен акцентным цветом/фоном.

## Компоненты, которые встречаются в макете повторно (кандидаты в `shared/ui`)

- **StatTile** — карточка с лейблом, крупным числом и дельтой (+X% / -X%) — используется на Dashboard
- **DonutChart с центральным числом** — "556 employees" в центре кольца
- **BarChart сравнения двух периодов** (beginning/end of year, два оттенка синего)
- **DataTable** — таблица с чекбоксами, сортируемыми заголовками (стрелка `↕` рядом с именем колонки),
  вложенными тегами (Job/Team badges)
- **Badge/Tag** — маленькие тёмно-серые пилюли с текстом (роль, команда, статус)
- **Tabs** — горизонтальные табы в карточке сотрудника (Info/Absences/Teams/...)
- **Avatar** — круглый, с fallback на инициалы/цвет, если без фото
- **Sidebar navigation** — иконка + текст + опциональный counter-badge (как "Mana 3")
- **Toast/inline notification** — зелёный "✓ Changes saved" в нижнем правом углу карточки

Зафиксируйте эти токены в `src/shared/styles/tokens.css` (CSS custom properties) до начала Дня 1 —
Tailwind-конфиг будет ссылаться на них через `theme.extend`, а не дублировать хардкод.
